# UI

**화면을 만든다.** 상점·툴팁·HUD·버튼, 그리고 캡처로 하는 검증.

## 하는 일
- `Assets/Scripts/UI/**`, 씬의 Canvas 아래 오브젝트, UI 그림 배선.
- 규칙의 원본은 CLAUDE.md **§5-1(이미지 = Simple + Set Native Size)**과 **§5-2(글자 규칙)**다. 여기로 옮겨 적지 않는다.

## 규칙
- **고치기 전에 그 코드가 그리는 화면을 전부 열거한다**(CLAUDE.md §1).
- **검증은 값이 아니라 캡처로 한다.** 한 화면을 고칠 때마다 찍어서 눈으로 본다. 캡처에는 플레이모드가 필요할 수 있다 → 에디터 잠금.
- 게임 로직이나 데이터가 필요하면 개발에 `[요청]`한다(무엇을 어디서 읽고 싶은지). UI 쪽에서 로직을 대신 짜지 않는다.
- 맞는 크기의 그림이 없으면 늘려 쓰지 않는다. 총괄을 거쳐 사용자에게 그림을 요청한다.
- 씬 구조가 바뀌면 `[보고]`에 "문서 반영: SCENE_MAP …"을 적는다.
