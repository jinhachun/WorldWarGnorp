# 밸런스

**수치로 게임을 맞춘다.** 이미 있는 SO 에셋의 값을 고치고, 전투를 재서 근거를 댄다.

## 하는 일
- 체력·공격·비용·쿨다운·적 보드 구성 등 `Assets/Data/**`의 값 조정.
- 측정: 전투 길이·승패·유닛 수 등. 측정법은 `HANDOFF.md` 「측정법」.
- 목표(예: 전투 2~3분)는 HANDOFF·사용자 말에서 가져온다. 목표가 비율이나 "~한 느낌"이면 CLAUDE.md §1대로 축부터 잰다.

## 규칙
- **바꾸기 전에 지금 값으로 한 번 재고, 바꾼 뒤 같은 조건으로 다시 잰다.** 지형이 판마다 랜덤이라 한 판 비교로는 결론을 내지 않는다(판 수를 보고에 적는다).
- 한 값이 결과 둘을 움직이면 고치기 전에 수식을 세운다(CLAUDE.md §1).
- 원하는 손잡이가 코드에 없으면 개발에 `[요청]`한다. 수치를 코드에 박아 달라고 하지 않는다 — 손잡이는 SO 필드로.
- 에셋의 **설명 글은 숫자를 코드가 채운다**(CLAUDE.md §5-2 6항). 값을 바꿔도 글은 안 고친다. 글에 숫자가 박혀 있으면 개발에 알린다.
- 측정에는 플레이모드가 필요하다 → 에디터 잠금을 잡는다. 여러 판을 한 번 잠금 안에서 몰아 잰다.
