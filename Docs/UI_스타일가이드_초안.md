# UI 스타일 가이드 (초안 · 10/21 — 사용자 검토 전)

> 사용자(10/21): "진짜 이게 실제 스팀 시장에 올라가도 되는 수준의 UI라고 생각해?"
> 이 문서는 **고를 거리**다. 확정되면 규칙만 남기고 CLAUDE.md §5-1·§5-2 옆에 포인터로 건다.
> 원본 규칙(그림 = Simple + Native Size · 글자 색 · 폰트 둘 · 아트 톤)은 CLAUDE.md §5·§5-1·§5-2에 있다 — 여기 옮겨 적지 않는다.

## 0. 진단 — 왜 "싸 보이나" (현재 화면 캡처 `Captures/UIUX1020/a0_nation.png` · `UIUX1021/after_states_map.png` 기준)

1. **픽셀 밀도가 화면마다 다르다.** 국가 선택의 기사는 그림 1px = 화면 약 18px(`NationCard` — 가장 긴 변을 256px 안의 최대 정수배로), 바로 옆 도트 글자는 1px = 2~4px, 기물 아이콘(`Assets/Sprites/Icons`, 80×80)은 16px 격자를 ×5로 그린 것으로 보이고, 줄 안 아이콘은 16px 원본. 한 화면에 픽셀 크기 4~5종이 섞이면 "조립한 화면"으로 읽힌다. 레퍼런스(Gnorp · He is Coming · Loop Hero)는 한 화면 안에서 픽셀 크기가 하나다.
2. **판 문법이 둘 이상이다.** 월드 골격은 회색 2px 선 + 이음매 매듭(`UI_WorldFrame`), 국가 선택·툴팁은 점 박힌 테두리 + 「+」 모서리(`NationFrame`), 시작 버튼은 회색 채움(`UI_ButtonMain`), 명령 버튼은 테두리 2중(`UI_CmdButton`). 같은 일(판 · 버튼)을 하는 것이 모양이 다르다.
3. **위계가 크기로만, 그것도 약하게 만들어진다.** 제목(36) · 이름(48) · 본문(Noto 약 28)이 비슷한 무게로 가운데 정렬 — 눈이 머물 곳이 없다.
4. **움직임이 없다.** 넘기기 · 고르기 · 확정이 즉시 바뀐다. Balatro · StS · He is Coming은 모든 입력에 0.1~0.2초 반응(튐 · 기울기 · 꺾쇠)이 있다.
5. **뒤 화면이 앞 판과 싸운다.** 채도 높은 지도 30칸 위에 판이 떠 있다.

## 3. 글자 크기 단계 (도트 = 12의 정수배 — §5-2-11)

| 단계 | 도트 | 깔끔(Noto) | 쓰는 곳 |
|---|---|---|---|
| 화면 제목 | 72 | — | 국가 이름 · 결과(승리!) — 화면당 하나 |
| 판 제목 | 48 | — | 판 · 카드 이름 |
| 소제목 · 버튼 | 36 | — | 버튼 글 · 목록 이름 |
| 라벨 · 숫자 | 24 | — | 수치 · 태그 · 키 안내 |
| 본문 | — | 22 | 설명 · 툴팁 본문 |
| 보조 | — | 18 | 회색 한 줄 |

규칙: **한 판 안에서 세 단계까지만.** 위계는 크기 차이 1.5배 이상 + 회색으로 만든다(같은 크기 둘이 나란히 무게를 다투지 않게).

## 4. 여백 단위

- **기본 단위 8px** — 모든 여백 · 간격은 8의 배수(8 · 16 · 24 · 32 · 48). 판 안쪽 여백 32, 묶음 사이 48, 줄 사이 8~16.
- 판 가장자리 ~ 화면 가장자리 최소 32.
- 정렬은 **왼쪽 기준선 하나** — 가운데 정렬은 제목 · 단일 버튼에만.

## 5. 움직임 규칙 (계단식 — 도트 톤이라 부드러운 이징 대신 프레임 단위)

| 사건 | 움직임 | 길이 |
|---|---|---|
| 올림 | 꺾쇠가 4px 밖에서 제자리로 붙음 | 2프레임(약 0.07초) |
| 누름 | 1px 아래로, 놓으면 복귀 | 즉시 |
| 고름 바뀜 | 이전 것 즉시 꺼짐 · 새 것 반전 + 내용이 8px 아래서 올라옴 | 0.1초 |
| 판 열림 | 위에서 16px 떨어지며 나타남(계단 3) | 0.12초 |
| 확정 | 판이 고른 대상 쪽으로 줄어들며 사라짐 · 바닥 유닛은 오른쪽으로 걸어 나감 | 0.3~0.4초 |
| 숫자 변화 | 굴러감 + 옆에 「+N」 떠오름(U18) | 0.3초 |

규칙: **모든 클릭은 0.1초 안에 눈에 보이는 반응.** 0.5초를 넘는 연출은 클릭으로 건너뛸 수 있게.

## 6. 화면 점검표 (UIUX.md 7단계 「사용성 검증」 때 같이 본다)

- [ ] 픽셀 크기가 한 화면에 하나인가(유닛 확대는 정수배 · 주변과 같은 배율)
- [ ] 판 · 버튼 · 탭이 §2 부품인가
- [ ] 글자 단계가 판 안에서 셋 이하인가
- [ ] 색이 영주 색 · 스탯 아이콘 · 이펙트 · 글자 색 넷 밖에서 쓰이지 않았나
- [ ] 화면에 이미 보이는 정보를 다시 쓰지 않았나
- [ ] 확정 버튼이 하나이고 늘 같은 자리인가 · 키 안내가 있나
- [ ] 모든 입력에 0.1초 반응이 있나
