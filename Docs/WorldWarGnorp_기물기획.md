# WorldWarGnorp 기물 기획

## 1. 게임 개요

- 더바자르식으로 일렬 칸에 **기물**을 배치하는 오토배틀러
- 기물이 발동하면 유닛이 소환되어 냥코대전쟁처럼 **사이드뷰**로 전투
- 본진도 화살을 쏘는 **타워**이며, 사거리가 늘면 적 본진 공격 가능
- 필드는 성 위로 쌓인 탑, 칸 하나가 한 층. 기물이 소환한 유닛은 그 기물의 층 높이에서 나와 앞으로 떨어짐 → 배치 전략은 **층 높이 / 위·아래 관계**로
- 기물 크기 없음 (전부 1칸, 소모품 없음)
- 등급: 일반 / 고급 / 희귀 / 영웅 / 전설 / 신화
- **등급·레벨 통합**: 표기 등급 = 시작 등급, 업그레이드 시 위 등급으로
- **신화**: 상점에 등장하지 않는다 — **전설 둘을 합쳐야** 나온다. 모든 기물이 신화에 도달할 수 있고, 기물마다 **새 효과 한 줄**이 붙는다(§7-1). 신화에서는 **수치가 오르지 않는다** — 쿨다운·효과 수치는 전설과 같다 (사용자 결정 10/12)
- **등급업**: 생산 기물(쿨다운마다 유닛을 소환하는 기물)은 등급이 오를 때마다 쿨다운 ×0.8 (값은 조정 중), 한 번에 소환하는 유닛 수는 그대로. 그 밖의 기물은 쿨다운이 아니라 효과 수치가 오름. 숫자가 없는 효과(노동의 기계화 · 조립식 감시탑 · 티크톡의 움직이는 성)는 등급 2부터 그 효과에 딸린 수치 하나가 붙음(§7 괄호). 조건 소환(성당기사단의 둘째 효과 · 조립 라인 · 대량보급 · 하마 교련장 · 왕족친위대)은 등급마다 소환하는 유닛 수가 늘어남

## 2. 설계 원칙

- 빌드 방향성(아키타입)을 먼저 정하고, 거기에 맞춰 기물 기획
- 밸런스보다 **재밌고 판을 바꾸는 빌드**가 우선
- 유닛 종류는 적게, 유닛을 다루는 방법(소환 방식·시너지)은 다양하게
- 전설은 규칙을 비트는 역할
- 쿨다운 없는 기물에 쿨다운 효과를 붙일 땐, 원래 효과가 주인공이고 쿨다운 효과는 정체성에 맞는 작은 덤으로
- 쿨다운 효과는 문구 첫 줄에 표기

## 3. 국가 구조

- **킹덤** / **티크톡** / **공용**
- 하스스톤 전장처럼 국가 기물이 섞여서 등장
- 국가가 많아지면 판마다 일부 국가만 등장
- 국가당 아키타입 2~3개, 기물 목표치 국가당 15~20개

| 국가 | 아키타입 |
|---|---|
| 킹덤 | 사제 / 중보병 성장 (교황파) · 경기병 무적 (왕당파) |
| 티크톡 | 타워 / 구매·경제 (자본가파) · 톱니병사 (노동자파) |

### 킹덤 세계관

- 교황이 모든 권력을 장악한 상황
- 공주 루니카가 왕권을 되찾기 위해 반군을 모음
- 꼭두각시 왕은 교황에게 실권을 빼앗긴 왕, 속으로는 왕권 회복을 원함
- **교황파**: 사제, 중보병 중심 / **왕당파·반군**: 경기병 중심
- 새 킹덤 기물은 "교황 쪽인가, 왕 쪽인가"를 기준으로 이름·효과 방향 결정

### 티크톡 세계관

- **자본가파**: 타워, 구매·경제 중심
- **노동자파**: 톱니병사, 톱니거인 중심

| 태그 | 유닛 |
|---|---|
| 경보병 | 병사, 톱니병사 |
| 중보병 | 방패수, 톱니거인 |

- 기물이 **유닛 이름**을 지칭하면 그 유닛에만 적용

## 5. 용어 / 키워드

- **기물**: 칸에 배치하는 모든 것 (건물, 인물, 장치 등)
- **인접 기물들**: 양옆 기물 모두에 효과를 줌 (탑 이전 표기 — 지금은 쓰지 않음)
- **인접 기물이 ~할 때마다**: 양옆 중 어느 쪽이든 조건을 만족하면 발동 (탑 이전 표기 — 지금은 쓰지 않음)
- **탑**: 필드는 성 위로 쌓인 탑. 칸 하나가 한 층 (칸 0 = 1층, 위로 쌓임)
- **아래에 있는 모든 기물**: 이 기물보다 아래층의 기물 모두
- **위에 있는 모든 기물**: 이 기물보다 위층의 기물 모두
- **바로 위 기물**: 한 층 위의 기물
- **바로 위·아래 기물들**: 한 층 위와 한 층 아래의 기물 모두
- **「구매할 때마다,」**: 구매 시 발동하는 효과 (하스스톤 전투의 함성 같은 키워드, 문구 통일)
- **「판매 시,」**: 판매할 때 발동하는 효과 (키워드, 문구 통일)
- **가속**: 일정 시간 동안 쿨다운이 2배 속도로 돎
- **무적**: 피해를 받지 않음
- **고도**: 머리 높이로 잰다 — 언덕, 점프, 크기, 타고난 키로 결정. 타워는 항상 높은 고도
- **크기**: 커지면 고도가 높아짐
- **내 타워들**: 내 본진과 내 작은 타워 전부. 타워에 주는 효과는 언제나 이 전부에 걸리고, 글도 언제나 「내 타워들」로 쓴다 — 「내 타워」·「해당 타워」·「타워」로 쓰지 않는다. 건축가가 짓는 것만 가리킬 때는 「작은 타워」
- **작은 타워**: 건축가(공격력 0)가 내 성에서 가까운 빈 평지부터 짓는 타워. 건축가는 짓고 나면 본진으로 돌아감. 본진과 같은 공격을 하고 공격력은 본진의 절반, 체력은 본진의 1/4. 적이 부술 수 있음. '내 타워들' 효과를 받음
- **목책**: 내 성 앞에 서는 구조물. 체력은 본진의 1/2. 내 유닛은 지나가고, 적은 부숴야 지나감
- **나무 다리**: 공병대가 기존 땅(언덕) 위에 얹는 나무 구조물. 맵을 절반으로 나눠 지은 쪽의 절반, 가운데 근처에 놓임 (양쪽이 모두 지으면 각자 자기 쪽에 하나씩). 위에 올라선 유닛은 고도가 높아짐. 적도 올라설 수 있음
- **전투 동안**: 이번 전투가 끝나면 초기화
- **영구히**: 런 전체 동안 유지 (기물을 팔아도 유지)
- **스택**: 쌓이는 수치
- **관통**: 화살이 적을 맞혀도 멈추지 않고, 땅에 닿을 때까지 경로상의 모든 적을 맞힘 (타워·궁병 화살은 포물선)

### 소환 처리 순서

1. 추가 소환 적용 (예: 대량보급 → 병사 2기)
2. 변환 적용 (예: 노동의 기계화 → 톱니병사 2기)

## 6. 스탯 표기 규칙

| 종류 | 표기 | 의미 |
|---|---|---|
| 고정 (Flat) | `공격력 +5` | 숫자가 그대로 더해짐 |
| 합연산 (Additive) | `공격력 +5%` | 모든 %를 더한 뒤 한 번에 적용 |
| 곱연산 (Multiplicative) | `공격력 ×1.1` | 각각 따로 곱해짐 |

- 계산 순서: **(기본 + 고정 합) × (1 + % 합) × 곱연산들**
- 쿨다운 감소는 0이 되지 않도록 **곱연산(×)으로 표기**

## 7-1. 신화 효과

기물이 신화 등급이 되면 §7의 효과는 그대로 두고 **아래 한 줄이 추가로 붙는다.** 수치는 전설과 같다.
세기 기준은 **기물마다 똑같이 「그 기물의 빌드가 판을 뒤집는 한 줄」**이다 — 시작 등급이 낮아 더 많이 합쳐야 하는 기물을 더 세게 하지 않는다 (사용자 결정 10/12).

## 8. 아키타입별 흐름

**킹덤 – 사제 (교황파)**
교회로 사제 확보 → 성수 우물로 회복 횟수 2배 → 수도원으로 회복할 때마다 기물 가속 → 교황청으로 궁수 기물이 사제 공장이 되고 사제가 광역 공격 → 승천의 전당으로 사제의 죽음을 공격력으로 전환

**킹덤 – 중보병 성장 (교황파)**
방패 공방·성당기사단으로 방패수 확보 → 사제·종탑의 회복으로 순례지 발동, 중보병 성장 → 크루세이더 길드로 커진 중보병이 힐러화 → 서로 회복하며 계속 커지는 순환

**킹덤 – 경기병 무적 (왕당파)**
마구간으로 기사 확보 → 루니카로 첫 피격 무적 + 무적 시 공격력 증가 → 꼭두각시 왕으로 적 사제 우선 사냥 → 왕족친위대로 처치 시 친위기사 연쇄 → 하마 교련장으로 죽어도 병사로 계속 싸움 → 공주의 축복·충정의 맹세로 무적 공급

**티크톡 – 타워**
화살 강화기·최신 엔진 부품으로 화력 → 조준연산코그로 처치마다 사거리 증가 → 오버드라이브로 공격속도 눈덩이 / 관통탄 특허국으로 줄 선 적을 꿰뚫는 화살비 → 사거리가 적 본진까지 닿으면 본진 공격

**티크톡 – 구매·경제**
「구매할 때마다,」 기물 수집 → 스팀바론으로 효과 2배 → 주식시장으로 골드 환급 → 영악한 투자가로 매 전투마다 구매 효과 재발동

**티크톡 – 톱니병사**
병영(+대량보급) + 노동의 기계화로 병사를 톱니병사로 전환 → 이동식 공장·교대근무계획서로 톱니병사 강화 → 스패너로 리롤할수록 곱연산 강화 → 조립 라인·철인공장 콜로서스로 톱니거인 엔드 (거인이 톱니병사 강화를 함께 받고, 걸으며 톱니병사를 생산)

## 9. 남은 결정 사항

- 수도원: 쿨다운 없는 기물에 가속이 걸리는 낭비를 허용할지
- 훈련용 허수아비: 현재 전장 유닛만인지, 이후 소환 유닛도 포함인지
- 순례지 / 크루세이더 길드: 증가량을 표기 규칙(+N / +N% / ×N)으로 수치화
- 타워 화살 여러 발이 한 적에게 몰리는지, 여러 적에게 퍼지는지
- 스패너를 팔면 스택이 사라지는지
- 친위기사 소환 위치 (본진 / 처치한 자리)
- 승천의 전당 + 루니카 공격력 +100%가 합연산으로 +200%(3배)인 것이 의도인지
- 킹덤 등급 분포가 위쪽이 무거움 (일반 1 / 고급 3 / 희귀 3 / 영웅 4 / 전설 5)
- 국가별 전설 5개 목표 (킹덤 5/5, 티크톡 6/5) / 공용 전설 1개 (판도라의 상자)
- 일반 기물 부족 (특히 킹덤 왕당파, 티크톡 노동자파 일반 0개)
- 티크톡: 「구매할 때마다,」 기물 종류 확충
- 중기병(전투코끼리, 공룡) 소속 국가 및 기물
- 이름 체크: 티크톡 (틱톡과 발음 유사)
- 등급·레벨 통합에 따른 기물별 등급업 효과는 빌드 뼈대 완성 후 일괄 작업
- 건축설계조합 등급을 희귀로 할지 (지금 구현은 희귀)
- 건축가 병종 태그를 지원병으로 할지 (지금 구현은 지원병)
- 성채의 '내 타워들 회복'이 작은 타워에도 걸리는지 (지금 구현은 걸림)
- 본진이 적 작은 타워를 쏘는지 (지금 구현은 쏨)
- 늪지: 쿨다운이 없는 기물이 전투 안에서만 꺼지는 것으로 할지 (지금 구현은 전투 안에서만 — 상점 효과와 이미 쌓인 영구 수치는 그대로)
- 나무 다리: 내 쪽 절반 안에서 정확히 어디에 놓는지 (가운데선 바로 옆 / 내 성 쪽), 길이와 높이
- 신화 테두리 색 (전설 = 주황 다음 색) · 신화 가격 — 코드의 등급 배열이 지금 5칸 (`BuildingRarity.cs`, `BattleConfig` 「등급」)
- 철인공장 콜로서스 신화 — 발사된 톱니병사가 주는 피해량 (피해를 준다는 것은 사용자 결정 10/12)
