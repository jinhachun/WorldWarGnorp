## 1. 국가 개요

- 극지방 원시부족. 괴수(중보병·중기병) 중심
- 컨셉: 부족원(경보병)이 죽어서 우두머리를 키운다
- 아키타입
  - **언덕·미노타우로스**: 원시 졸병이 죽으며 뼛가루 언덕을 쌓고, 언덕 위 미노타우로스가 강해짐
  - **맘모스 몰빵**: 유닛이 죽으며 "공격력이 가장 높은 내 유닛"에게 회복·공격력을 몰아줌
- 새 키워드 없음. 아래 공통 규칙(대상 선택, 뼛가루 언덕)으로 구현

## 2. 공통 규칙

### 2-1. 대상 선택 문구

| 문구 | 판정 |
|---|---|
| 공격력이 가장 높은 내 유닛 | 효과 발동 시점에 전장에 살아 있는 내 유닛 중 **현재 공격력**(버프 적용 후) 최댓값. 사망 처리 중인 자기 자신은 제외. 동률이면 무작위 **[TBD]** |
| 쿨다운이 가장 긴 내 기물 | 내 보드 기물 중 **기본 쿨다운** 최댓값. 쿨다운 없는 기물 제외. 동률이면 무작위 **[TBD]** |
| 무작위 내 중보병 / 무작위 내 기물 | 균등 확률. 대상이 없으면 효과 없음 |

### 2-2. 뼛가루 언덕 (지형)

- 원시 졸병 사망 시 그 자리에 뼛가루가 떨어짐
- **가루처럼 쌓임**: 같은 자리에 겹칠수록 높아지고, 옆으로 완만하게 퍼짐 (경사면 형성)
- 언덕 높이 = 그 위 유닛의 **고도**
- 아군·적 **모두** 올라가서 고도 이득을 받음
- 일반 언덕(맵 지형)과 구분되는 **"뼛가루 언덕"** 태그 필요 (저주의 뼈언덕·전쟁 북소리 판정용)
- 전투 동안 유지, 전투 종료 시 초기화
- 뼛가루 1회 분량 = 고도 몇인지 **[TBD – 테스트로 조정]**

### 2-3. 고도

- 결정 요소: 언덕(지형·뼛가루), 점프, 크기
- 실시간 값. 언덕을 내려오면 즉시 감소

### 2-4. 기존 공통 규칙 (참고)

- 스탯 계산: (기본 + 고정 합) × (1 + % 합) × 곱연산들
- 쿨다운 기물은 가속·쿨다운 감소(풍차, 물레방앗간 등) 적용
- 소환 처리 순서: 추가 소환 → 변환
- "전투 동안" 효과는 전투 종료 시 초기화

## 5. 기물별 구현 메모 / 엣지 케이스

**전쟁 북소리**
- 버프 대상: 발동 순간 뼛가루 언덕 위에 있는 내 유닛. 받은 버프는 언덕을 내려가도 전투 동안 유지
- 같은 유닛이 여러 번 받으면 누적

**저주의 뼈언덕**
- 디버프 대상: 발동 순간 뼛가루 언덕 위에 있는 적. 언덕을 내려가도 전투 동안 유지, 누적

**바위의 토템**
- 내 중보병이 없으면 효과 없음 (다른 국가 중보병도 대상 포함)

**툰드라 행진**
- 원시 졸병도 경보병이므로 **연쇄 발동이 의도**됨 (매 사망마다 30% 판정)

**제물의 의식**
- 무작위 대상에 **자기 자신 포함** (걸리면 다음 발동이 밀림, 의도)
- 처리 순서: 무작위 기물 정지 → 인접 기물들 즉시 발동 **[TBD]** (정지된 기물이 인접 기물이면 즉시 발동은 되고 이후 10초 정지)
- 정지 중엔 쿨다운이 흐르지 않음. 가속도 적용되지 않음

**죽지 않는 전사**
- 사망할 때마다 매번 25% 판정 (부활한 유닛도 다시 판정)
- 부활 위치: 사망한 자리
- 부활 시 체력 **[TBD]** (최대 체력 회복 추천)
- 사망 시 효과(뼛가루, 회복, 공격력 바치기 등) 발동 여부 **[TBD]** — 추천: 사망 시 효과 발동 후 부활
- 부활은 "소환"으로 치지 않음 (소환 트리거 기물 미발동) **[TBD]**

**대족장의 분노**
- 판정 시점에 내 미노타우로스가 1기 이상 살아 있으면 소환 대신 버프
- 최대 체력 증가 시 현재 체력도 같은 양만큼 증가 **[TBD]**

**거대 괴수의 무덤**
- 모든 경보병 소환에 반응 (다른 국가 병사·톱니병사, 툰드라 행진의 졸병 포함)
- 중기병 공격력 버프는 발동 시점 전장의 중기병에 적용 / 이후 소환 포함 여부 **[TBD]**

**약탈족장 라이칸스로프**
- 처치 카운트: 내 유닛과 타워의 처치 모두 포함 **[TBD]**, 전투마다 초기화
- 즉시 발동은 추가 발동이며, 대상 기물의 쿨다운은 리셋하지 않음 **[TBD]**

**원시 의식 제단**
- 대상이 공격할 때마다 실시간으로 "공격력이 가장 높은 내 유닛" 판정
- 맘모스 광역 공격은 맞힌 대상 전체 피해 합 기준 **[TBD]** (아군 피해 포함 여부도 확인)

## 6. 주요 시너지 (테스트 시나리오)

1. **언덕 쌓기**: 뼈무덤 + 전쟁 북소리 + 툰드라 행진 → 졸병 연쇄 사망으로 언덕 높이 증가 → 미노타우로스 족장 등장 후 공격력·공속 확인
2. **언덕 쟁탈**: 적이 뼛가루 언덕에 올라왔을 때 저주의 뼈언덕 디버프 / 적의 고도 이득 동시 적용 확인
3. **맘모스 몰빵**: 부족의 최종병기 + 전사의 움막 + 약탈 전초기지 → 맘모스 아군 피해로 원시의 전사·툰드라 전쟁소 사망 → 맘모스 회복·공격력 증가 확인
4. **전설 재발동**: 약탈족장 라이칸스로프 + 부족의 최종병기 → 10킬마다 맘모스 추가 소환
5. **부활 보험**: 죽지 않는 전사로 맘모스 부활 시 버프 유지 확인
6. **국가 간**: 거대 괴수의 무덤 + 티크톡 병영/노동의 기계화 → 톱니병사 소환·사망에 반응 / 킹덤 순례지 + 미노타우로스(중보병) 회복 성장

## 결정 기록(10/13)

위 본문은 사용자가 쓴 기획안 그대로다(`Downloads`의 원본을 복사 — 본문은 고치지 않았다). 이 절은 기획 담당이 붙였다. 총괄이 명세와 지금 게임이 어긋나는 곳 여섯을 표로 물었고, 사용자가 번호로 답했다. **본문과 이 절이 다르면 이 절이 뒤의 결정이다.**

- [결정] **고도의 기준 = 맵에서 가장 낮은 땅.** (「고도는 맵에서 가장 낮은 땅 기준으로 해줘」) — 고도 = 유닛 발 높이 − 그 맵의 가장 낮은 땅 높이.
  - [가정 — 총괄] 단위는 1 = 1칸이다.
  - 귀결: 맵의 원래 언덕도 고도가 된다 — 자연 언덕 위의 미노타우로스는 뼛가루 없이도 강해진다. (총괄이 사용자에게 알렸고 정정이 없었다)
- [결정] **아군을 밟고 올라선 높이도 고도로 친다.** (「아군 밟고 올라선 높이도 고도로 쳐」) — §2-3의 결정 요소(언덕 · 점프 · 크기)에 더해진다.
- [결정] 제물의 의식의 「인접 기물들」 → **「바로 위 · 아래 기물들」.** 탑 구조의 낱말이다. (사용자 「그래」) — §4 영웅 표와 §5 제물의 의식 메모의 「인접 기물」이 모두 이렇게 읽힌다.
- [결정] **기물 15개의 신화 효과 15줄은 지금부터 정한다.** (「신화 15줄 지금부터 정해야해」) — 총괄의 초안에 사용자가 「좋네」라고 했다. 아래 「신화 효과 15줄」.

- AI끼리의 승패 식(탑 전투력 — `TowerPower`)에서 트라이브 언덕 방향이 여덟 방향 중 가장 낮게 나온다(36.9) — 뼛가루 · 고도 · 조건 소환이 식에 안 잡힌다. 맘모스 몰빵은 47.2로 가운데다.
