2. UI상단 기물 밑에 적혀있는 숫자가 전투에서 바뀔경우 실시간으로 수치가 표시되어야함. ex) 허수아비로 인해 현재 상승한 공격력 수치가 인게임에 표기되어야함
3. 산이 쌓이고 적과 라인이 형성되기 위해서는, 아군이 앞에 있을때는 적극적으로 점프해야하지만, 적이 앞에 있을 때는 점프를 적게 할 필요가 있음.
4. 구매했을때마다, 전투시작시, 가속 등의 효과에 UI상 시각적 피드백이 없음. 
5. 골드 밸런스의 문제가 있음. Batomon showdown의 골드 밸런스를 참고해서 기물별 가격, 리롤 가격, 획득 골드를 재산정할 필요가 있음.
6. 데스 매치의 도입은 좋은 판단이었음.
7. 인게임 버프에 대한 시각적 피드백이 필요할듯함. 예를 들어 무적 상태일때는 노란 원이 감싼다던지, 공격버프를 받을 때는 빨간 오라 효과가 붙는다던지.
