1. castle.png의 이미지 크기와 모양을 변경했음. 기물 탑이 성 안에 있는거처럼 보이게, 기물의 모양을 맞춰주고, 맨 위에 진형색 지붕이나 깃발도 달아줘.
2. 화면상으로 성에 있는 탑이 보이면 기물 UI를 감추고, 탑이 보이지 않으면 해당 UI를 띄워줘. 이건 적 진영도 마찬가지야.
3. 성에 있는 타워도 UI처럼 해당 효과의 진행상황 등이 보여야해.
4. 상점에 잠금 기능 좀 만들어줘. 누르면 다 잠기고, 다음 라운드에 그대로 나오는거임
5. 바닥 언덕이 더 다이나믹하고 다양하게 나왔으면 좋겠어. 다양한 맵들도 있으면 재밌을 거 같아.

기본 : 평범한 지형입니다. 
숲 : 궁병의 공격이 반감되는 대신, 모든 유닛의 이동속도가 감소합니다.
초원 : 경기병과 중기병의 이동속도가 증가합니다.
얼음 : 모든 기물의 쿨다운 속도가 절반으로 감소합니다. 5초마다 모든 기물을 발동합니다.
정글 : 모든 기물의 쿨다운 속도가 2배로 진행됩니다.
