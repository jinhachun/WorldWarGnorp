# 팝업 · 이벤트 화면 · UI 손맛 계획 (10/31 총괄 — 계획만, 구현 전)

> 사용자: 「모든 UI 쥬시하게 · 이벤트 상황에 맞는 이벤트 화면 · 팝업 애니메이션 다 만들어야 해. 그 전에 계획 짜서 알려줘」
> 이어지는 문서 — `Docs/폴리싱_계획.md`(J0~J5 · 전투 · 상점 손맛, 끝남). 이 문서는 **아직 즉시 켜지는 화면**과 **전용 화면이 없는 순간**만 다룬다.

---

## 0. 지금까지 사용자가 정한 취향 (이 계획의 바닥)

- **움직임은 좋고 번쩍임은 싫다** — 큰 면적이 강한 색으로 번쩍이면 눈이 아프다(10/31).
- **글자가 쾅 떨어지는 연출은 싫다** — 「전투!」 · 승리/패배 글자 쾅은 「구리다」로 뺐다(10/31).
- **잠깐 멈춤(히트스톱)은 하지 않는다.**
- 픽셀 격자 — UI 1칸 = 3px 단위로 움직이고, 도트 글자는 12의 배수 크기만.
- 이미 있는 판 열림 문법 — **위 16px에서 0.12초 동안 3계단으로 내려앉기**(이벤트 방문 · 닉네임 · 결과 창). 새 팝업도 이것에 맞춘다.

## 2. 전용 화면이 없는 순간

| 순간 | 지금 보여 주는 것 |
|---|---|
| **통일(런 승리)** | 왼쪽 알림 판 글 두 줄 + 「새 런」 |
| **게임 오버** | 같은 알림 판 |
| **국가 위기 진입**(목숨 0) | 업그레이드 카드 창 머리말 한 줄 |
| **내가 영주를 멸망시킴** | 결과 창 한 줄 + 지도에서 영주가 날아감 |
| **연합 물러남 · 연합 멸망** | 결과 창 한 줄 |
| 나라 소식 10종 | 팝업은 있으나 **10종 모두 같은 무대**(내 영주 하나) · 고른 뒤 결과 연출 없이 닫힘 |
| 외교 수락(통상 체결) | 결과 연출 없음 |
| 반란 · AI 영주 소멸 | 지도 색 변화 + 요약 글 |
| 유령 영주(다른 플레이어 기록) | 표시 없음 |

## 4. 단계 (단계마다 영상 → 사용자 확인 → 다음)

### K1. 팝업 공통 열림 · 닫힘 (부품 하나)
- 공용 부품 `UI/PopupMotion` — 열림 = 어둠 3계단 짙어짐 + 판 3계단 내려앉기(지금 문법), 닫힘 = 반대로 2계단 올라가며 흐려짐. 시간은 실제 시간.
- 붙일 곳: 업그레이드 고르기 · 왼쪽 알림 판 · 이벤트 방문/소식/외교/연합 **닫힘** · 국가 고르기 처음 열림 · 지형 배너 나타남.
- 업그레이드 카드는 진열 카드처럼 **왼쪽부터 차례로 들어온다**(상점 J3와 같은 튐).

### K2. 이벤트 화면 (Q1 · Q2 답대로)
> 🔴 **장면은 그 상황의 이야기를 그린다**(사용자 10/31) — 소품만 바꾼 무대는 「상황과 아무 연관이 없다」. 국가 위기 = 백성들이 모여 팻말(신화 업그레이드 셋)을 들고 영주에게 요구 → 사용자 「좋은 거 같아」.

- 이벤트 방문 팝업의 무대(지형 뒷배경 + 인물 + 소품 + 제목 · 한 줄)를 **장면 판**으로 쓰고, §2의 순간마다 장면을 하나씩 짠다. 새 시스템이 아니라 같은 판의 새 장면.
  - 통일 — 내 영주가 왕관 아래, 내 땅 수 · 턴 수 · 「새 런」.
  - 게임 오버 — 무너진 성 · 깃발 쓰러짐, 이번 런 한 줄 · 「새 런」.
  - 국가 위기 — 빈 하트 · 어두운 무대, 카드 고르기 앞에 한 장면.
  - 영주 멸망 · 연합 물러남/멸망 — 쓰러진 영주 · 깃발이 내 색으로 바뀜.
- 나라 소식 10종 — 소식마다 소품 하나(풍년 = 곡식 · 금광 = 광석 · 대화재 = 불 …)를 무대에 세우고, 고른 뒤 **결과가 날아가는 연출**(이벤트 방문의 결과 비행 재사용).
- 외교 수락 — 두 영주가 마주 서서 깃발이 맞닿는 짧은 장면.
- **사용자 결정 11/1**
  - 나라 소식 — 선택지 = 무대 물건 + 하늘 글 칸 둘 다(짝끼리 서로 밝아짐) · 상점 효과는 무대에 짧은 글만 · 손님 인물은 공용으로 새로 그림 · 틀마다 하나(이주민 · 풍년 · 대화재) 먼저 확인 후 나머지.
  - 외교 수락 = 마주 서서 같이 폴짝 + 그 나라 짐수레(교역). 거절 = 상대가 돌아서 나감.
  - 반란 · AI 영주 소멸은 팝업 없이 지도 위 연출(반란은 그 턴의 것을 한꺼번에). 유령 영주는 장면 없이 이름표 옆 배지(가리킬 때만) + 「다른 플레이어의 기록」 회색 줄.
  - 골드 동전은 얻는 곳 · 내는 곳 전부 인크리멘탈 게임식 한 종류로(터짐 → 머묾 → 빨려 들어감 → 닿을 때마다 숫자 · 아이콘 톡).

### K3. 남은 HUD
- 배속 버튼 · 전투력 막대 나타남, (Q4가 b면) 호버 카드 · 설명 창.

### 하지 않는 것
- 글자 쾅 · 큰 면적 색 번쩍임 · 히트스톱(§0).
- 소리(J6 — 이번엔 자리 주석만).

## 5. 검증
- 단계마다 Recorder 영상(`Editor/Dev/VideoCapture`) — 화면마다 열림 · 닫힘 한 번씩.
- 게임 오버 · 통일 · 국가 위기는 지금까지 눈으로 본 적이 없다 — 치트로 그 상황을 만들어 찍는다(기록은 남기지 않음).
- 「쫀득한가」는 사용자만 판정.
