## 1. 참고한 인디 게임 — 가져올 기법만

| 게임 | 가져올 것 |
|---|---|
| **Hades** · **Hollow Knight** · 격투 게임류 | **잔상 체력바** — 맞으면 바가 즉시 줄고, 깎인 구간은 흰 막대로 남았다가 잠깐 뒤 따라 줄어든다. "얼마나 맞았나"가 한눈에 |
| **Nuclear Throne** · **Vlambeer 「Art of Screenshake」** | 피격 **1~3프레임 정지(히트스톱)** · 흔들림은 *세기를 쌓는(trauma)* 방식 · 발사 섬광 · 사망 순간 번쩍 — *"작은 것도 아주 짧게"* |
| **Balatro** | 숫자가 **커졌다 탄성으로 돌아옴**(크기 튐) · 점수 굴러 올라감 · 카드 호버 기울기 · 모든 버튼 눌림. 큰 값일수록 더 크게 흔들림 |
| **Vampire Survivors** · **Brotato** | 몹이 많을 때 — **흰 실루엣 번쩍** 1프레임 · 숫자는 작게 많이. 히트스톱은 *안 건다*(많으면 끊김으로 보임) |
| **The Bazaar** · **Backpack Battles** · He is Coming | 아이템(우리 기물) 발동 = 칸이 **탄성 튐 + 테두리 섬광** · 쿨다운 끝나는 순간이 읽힌다 |
| **Gnorp Apologue** (아트 톤 원본) | 흰 몸 · 검은 바탕에서 **색 파편 · 숫자가 화면을 채우는** 쾌감 — 우리 색 규칙(색은 이펙트만) 그대로 |

**우리 게임에 맞춘 원칙**
1. **유닛이 많다 → 일반 타격은 "작게 · 짧게", 큰 순간만 "크게"**(본진 피격 · 큰 넉백 · 처치 연쇄 · 무너짐). 모든 타격에 히트스톱을 걸면 Vampire Survivors처럼 끊긴다.
2. **픽셀 격자를 지킨다** — 늘리고 줄이는 튐은 *그림 1px 단위로 끊어서*(지도 땅 펄스에서 점이 고르지 않게 늘던 문제를 되풀이하지 않는다).
3. **세기는 숫자 하나로 조절** — 흔들림 · 정지 · 튐 크기를 `BattleConfig`에 모아, 밸런싱 창에서 한 번에 줄였다 늘린다(옵션 「화면 흔들림」 켜고 끄기까지 이어짐).

## 2. 단계 (위에서부터 — 단계마다 캡처 · 사용자 확인 후 다음)

### J0. 공용 부품 (보이는 변화 없음 · 작음)
- `Fx/Juice` — 이징 곡선(탄성 · 감속) · **Punch**(크기 튐 → 탄성 복귀, 1px 단위 끊기) · 숫자 굴림. 지금 파일마다 손으로 쓴 Lerp를 *새로 만드는 것*부터 이것으로.
- 세기 값(흔들림 · 정지 · 튐 배율) → `BattleConfig` 「손맛」 묶음.

### J1. 체력바 (사용자가 콕 집은 것 — 먼저)
- **본진 바**: 즉시 줄어드는 채움 + **흰 잔상 바**(0.4초 기다렸다 감속하며 따라 줄어듦) · 맞는 순간 바 전체 1프레임 흰 번쩍 + 2px 흔들림 · 숫자 튐 · 체력 30% 아래면 바가 천천히 붉게 숨쉼.
- 회복은 반대 — 초록 잔상이 먼저 차고 채움이 따라 찬다.
- **유닛 바** — §3 Q1 답에 따라.
- 그림: 바 틀 · 채움은 지금 그림 그대로(새 그림 없음 — Simple · Filled 규칙 유지). 틀이 아쉬우면 **아트에 요청**(§4).

### J2. 전투 타격감
- **피격 번쩍임** — 흰 몸에 흰 번쩍은 안 보인다 → **1프레임 검은 실루엣 → 노랑**(반전 깜빡) — §3 Q3.
- **숫자** — 나올 때 1.6배 → 1배 탄성 · 큰 타격(최대 체력 대비 큼)은 더 크게 + 1px 떨림 · 처치한 일격 숫자는 한 단계 크게.
- **히트스톱** — 일반 타격 없음 · *처치* 0.03초 · 큰 넉백 0.06초(지금) · 본진 피격 0.05초. 1초 간격 제한은 유지.
- **근접 돌진** — 공격할 때 몸이 1px 앞으로 쏠렸다 돌아옴(무기 찌름과 함께).
- **발사 섬광** — 궁병 · 타워 활 끝에 1~2px 흰 점 1프레임.
- **사망** — 죽는 순간 흰 실루엣 1프레임 → 시체 날아감(지금).
- **본진 피격** — 성 그림 1px 흔들림 · 흰 번쩍 · 약한 화면 흔들림(같은 프레임 여러 발은 묶음).
- **무너짐** — 마지막 일격에 정지 0.15초 + 강한 흔들림 → 지금 연출.

### J3. 상점 · UI 손맛
- **버튼 공통** (`ButtonHover`) — 호버 1px 떠오름 · 누르면 내려앉음 + 놓을 때 탄성 · 비활성 버튼 누르면 좌우 흔들림.
- **칸 · 탑 층 튐** — 선형 → 탄성(오버슈트) 한 줄 교체.
- **판매** — 기물이 작아지며 동전 3~5개가 골드 칸으로 날아감(전투 동전 연출 재사용) · 골드 숫자 튐.
- **골드 · 하트** — 골드 숫자 굴러감 + 튐 · 목숨 잃는 순간 하트가 깨지며 떨어짐.
- **끌기** — 들고 있는 기물이 움직이는 방향으로 살짝 기울고(픽셀 단위 · 1단계), 놓을 때 칸에 탁 앉는 튐.
- **리롤** — 버튼 눌림 + 진열 카드가 차례로 튐.

## 3. 먼저 정할 것 (손맛 · 방향이 갈리는 것)

> **사용자 결정 10/31** — Q1 (b) 맞은 유닛만 잠깐 · Q2 (c) 이번엔 소리 없이(자리만) · Q3 (a) 검은 실루엣 → 노랑 · Q4 (a) Balatro처럼 진하게.
> **J2 영상 뒤 사용자 결정 10/31** — 검정→노랑은 눈이 아프다 → 유닛 번쩍임은 노랑만(J2 전 그대로) · 본진은 색 번쩍임 없이 흔들림만. 히트스톱(처치 · 본진 피격 · 무너짐 정지)은 하지 않는다. 숫자 크기는 피해 비율 · 처치가 아니라 **때린 유닛의 크기** — 1이면 보통, 2 이상이면 큰 숫자.

- **Q1 유닛 체력바** — (a) 늘 보임 · (b) **맞은 유닛만 2초 보였다 사라짐**(추천 — 유닛이 많아 늘 보이면 화면이 바글거린다) · (c) 지금처럼 호버만.
- **Q2 소리** — (a) 무료 효과음 묶음에서 고르기(라이선스 확인) · (b) 사용자가 직접 · (c) 이번엔 자리만(소리 없음).
- **Q3 피격 번쩍임** — (a) 검은 실루엣 1프레임 → 노랑(추천) · (b) 지금 노랑 그대로 · (c) 색 파편만 늘림.
- **Q4 세기** — (a) **Balatro처럼 크게**(흔들림 · 튐 진하게) · (b) 깔끔하게 약하게. 밸런싱 창 숫자 하나라 나중에 바꿔도 된다 — 첫 값만 정하면 된다.

## 4. 그림 요청 (아트 — 필요할 때만)
- 체력바 틀이 지금 단색 판이면 그대로 간다. 바꾸고 싶으면: 본진 바 틀(원본 크기 그대로 쓰는 Simple 규칙 — 크기는 그릴 때 정한다).
