# Gnorp War

냥코대전쟁 / Age of War 스타일의 2D 사이드뷰 라인 디펜스 RTS.
Gnorp 군대를 소환해 적 기지를 먼저 무너뜨리세요.

## 요구 사항
- Unity **6000.3.16f1**

## 실행 방법
1. Unity Hub에서 이 폴더(`WorldWarGnorp`)를 프로젝트로 추가
2. 에디터에서 전투 씬을 열고 Play (씬 경로는 전투 씬 생성 후 기입)
